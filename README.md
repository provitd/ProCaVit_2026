This directory contains scripts of the bioinformatic analysis of the paper https://doi.org/10.1038/s44321-026-00417-5.

# Description of the directory

The analysis is seperated into two files:
 - [RNAseq.qmd](RNAseq.qmd): contains DGE and GSEA analysis with associated heatmaps using DESeq2 and clusterProfiler
 - [scRNA.qmd](scRNA.qmd): contains QC, normalization, integration, dimension reduction, clustering, annotation, markers, DGE and pathway analyses using Seurat and clusterProfiler
